## Open Chat
Open Chat is an app based off of the SMP protocol, (Schneidermans Messaging Protocol)
which is based off of Cloudlink, it can send files and messages through the network
also, its open source for anyone to look at, copy and use. Please choose this project
to make a messaging app, make a custom version, or just for daily use.
Use at https://schneiderman4907.github.io/Open-Chat/ we recommend downloading
a nerd font for everything to render correctly but it isnt required.
